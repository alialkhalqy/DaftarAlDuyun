# دفتر حسابات – مشروع Android

## ما يتضمنه هذا الإصدار
- تطبيق Android أصلي باستخدام Kotlin وJetpack Compose.
- قاعدة بيانات Room محلية على الهاتف.
- سجل معاملات: بيع نقدي، بيع آجل، تحصيل، دين مورد، سداد مورد، مصروف، إيراد، وضمار.
- شاشة إدارة الزبائن والموردين.
- ملخص مالي وتقارير تجميعية أولية.
- تعديل مسميات الأقسام الافتراضية وحفظها محلياً.
- ربط معاملات الديون والتحصيل والسداد بمعرّف الزبون أو المورد.
- عرض رصيد كل زبون ومورد وكشف آخر معاملاته.
- إدخال تاريخ استحقاق للديون الآجلة وديون الموردين.
- تأكيد قبل حذف المعاملة.
- تعديل مبلغ المعاملة والاسم والتكلفة والملاحظات.
- تصدير سجل المعاملات إلى CSV المتوافق مع Excel ومشاركته.
- إنشاء كشف PDF أساسي ومشاركته عبر تطبيقات الهاتف.
- لا توجد صلاحيات إنترنت في AndroidManifest.

## فتح المشروع
1. ثبّت Android Studio على الكمبيوتر.
2. فك ضغط ملف المشروع.
3. افتح مجلد `DaftarAlDuyunAndroid` من Android Studio.
4. اسمح بمزامنة Gradle.
5. شغّل التطبيق على هاتف Android أو المحاكي.

## ملاحظات مهمة
هذه نسخة تأسيسية قابلة للتطوير وليست إصداراً تجارياً نهائياً. لم يتم تجميع APK أو اختبار المشروع على جهاز فعلي ضمن هذه البيئة.
قبل النشر يجب استكمال:
- استكمال تحرير المعاملات وتعديل بيانات الأشخاص وحذفهم بأمان.
- احتساب الأرصدة حسب كل طرف مع دعم الدفعات الجزئية وتواريخ الاستحقاق.
- تعديل/حذف العمليات مع سجل تدقيق وحماية من أخطاء الإدخال.
- التصفية الزمنية الصحيحة للتقارير.
- تصدير PDF وExcel ومشاركة كشف الحساب.
- نسخ احتياطي واستعادة محليان مع تشفير.
- قفل التطبيق برقم سري/بصمة.
- اختبارات وحدات واختبارات واجهة، وترقية مخطط قاعدة البيانات.
- إعداد أيقونة التطبيق وملف التوقيع النهائي.

## العمل دون إنترنت
التطبيق لا يطلب صلاحية INTERNET، وتُحفظ البيانات في قاعدة Room داخل مساحة التطبيق الخاصة.
**تنبيه:** حذف التطبيق أو مسح بياناته قد يحذف قاعدة البيانات؛ لذلك يجب إضافة النسخ الاحتياطي المحلي قبل الاعتماد التجاري.


## تحديث المرحلة الرابعة: النسخ الاحتياطي والاستعادة
- إضافة إنشاء نسخة احتياطية كاملة بصيغة JSON عبر منتقي الملفات في Android.
- إضافة استيراد نسخة احتياطية والتحقق من نوع الملف وإصداره والبيانات الأساسية.
- الاستعادة تتم ضمن معاملة Room واحدة، مع تأكيد واضح قبل استبدال البيانات الحالية.
- لا يتطلب ذلك اتصالاً بالإنترنت أو صلاحيات تخزين عامة.

## ما لم يكتمل بعد
- قفل التطبيق برمز PIN أو بصمة وتشفير قاعدة البيانات.
- تنبيهات الاستحقاق والتكامل مع WhatsApp.
- تحسين PDF لدعم تشكيل العربية واتجاه RTL.
- تقارير يومية وأسبوعية وشهرية، ومراجعة منطق الصندوق والربح والدفعات الجزئية.
- لم يتم بناء APK أو اختبار المشروع على هاتف Android فعلي؛ يجب فتحه في Android Studio ومزامنة Gradle وفحص البناء.
- احفظ النسخة الاحتياطية خارج الهاتف؛ حذف بيانات التطبيق أو إلغاء تثبيته قد يؤدي إلى فقد قاعدة البيانات المحلية.


## تحديث الهوية البصرية – واجهة المقدمة
- إضافة شعار مرئي للتطبيق على شكل محفظة مالية داخل بطاقة هوية بلون أخضر وذهبي.
- إظهار الاسم العربي: «دفتر حسابات».
- إظهار الاسم الإنجليزي: «Accounts Book».
- إضافة عبارة المطور: «برمجة علي حسين الخلقي».
- إضافة الاسم الإنجليزي المختصر في شريط العنوان العلوي أيضاً.
